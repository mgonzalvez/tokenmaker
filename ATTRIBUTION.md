## Fractal Symbols: Board Game Library

- Creator: Felix Thalin
- Original library: <https://fractalsymbols.com>
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- Included formats: SVG and PNG
- Use in TokenMaker: searchable source artwork that users may recolor, outline, scale, rotate, combine with a numeric value, and place inside token shapes

The complete upstream license text is preserved at:

`Fractal-Symbols-Complete-Pack/License.txt`

The upstream readme is preserved at:

`Fractal-Symbols-Complete-Pack/Readme.txt`

TokenMaker also includes non-duplicate legacy vectors preserved from:

`FractalSymbols Icons Set/`

TokenMaker may normalize SVG paint attributes at render time so user-selected fill and stroke colors can be applied. The original supplied source files remain preserved in the project.
